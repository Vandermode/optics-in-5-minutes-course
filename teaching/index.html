THE EPISODE INDEX

Ten episodes. Many ways in.

Episode numbers identify the material. Choose by concept or interest, and review the foundations each lesson uses.

E01 / FILM + LESSON + PYTHON LAB

The angular spectrum method

Follow a slit field into space by changing the representation: separate its directions, advance their phases, and add them back.

Key concepts
  • Plane waves
  • Angular spectrum
  • Spatial frequency
  • FFT
  • Evanescent waves
E02 / FILM + LESSON + PYTHON LAB

Why a lens computes a Fourier transform

A lens sorts plane waves into focal spots. A second lens turns that spectrum back into an image—and lets you edit it along the way.

Key concepts
  • Fourier transform
  • 4f system
  • Spatial filtering
  • Phase contrast
E03 / FILM + LESSON + PYTHON LAB

The diffraction limit

Explore point spread functions, numerical aperture, and the spatial frequencies an image can carry.

Key concepts
  • Point spread function
  • Numerical aperture
  • Optical transfer function
  • Diffraction limit
  • Deconvolution
E04 / FILM + LESSON + PYTHON LAB

Coherence and what a camera averages

Connect interference, source bandwidth, source size, and speckle through one measurement: the time-averaged squared field.

Key concepts
  • Temporal coherence
  • Spatial coherence
  • Spectral bandwidth
  • Coherence length
  • Speckle
E05 / FILM + LESSON + PYTHON LAB

Holography and the phase problem

Turn a phase difference into measurable fringes, recover a complex field from a sideband, and learn what iterative constraints can—and cannot—determine.

Key concepts
  • Interference
  • Off-axis holography
  • Phase retrieval
  • Gerchberg–Saxton
E06 / FILM + LESSON + PYTHON LAB

Flat optics and wrapped phase

A thin element controls phase through height. Wrapping that phase makes a shallow optic, while quantization and colour reveal the price of the simplification.

Key concepts
  • Phase wrapping
  • Diffractive optics
  • Phase quantization
  • Chromatic aberration
  • Thin-element approximation
E07 / FILM + LESSON + PYTHON LAB

Gratings, Bloch waves, and band gaps

Use momentum matching to find diffraction directions, then use a period’s transfer matrix to explain why a stack can reject a band of frequencies.

Key concepts
  • Diffraction orders
  • Bloch waves
  • Photonic band gaps
  • Bragg reflection
  • RCWA
E08 / FILM + LESSON + PYTHON LAB

Waveguides, modes, and resonators

Find the field shapes that can travel unchanged, combine them to transfer power between guides, and sum repeated round trips to build a resonance.

Key concepts
  • Waveguide modes
  • Evanescent coupling
  • Ring resonators
  • Quality factor
  • Critical coupling
E09 / FILM + LESSON + PYTHON LAB

Maxwell on a grid

Solve Maxwell’s coupled field equations with staggered samples, then find out why time steps, pixels, and computational boundaries are part of the physics calculation.

Key concepts
  • FDTD
  • Yee grid
  • CFL condition
  • Numerical dispersion
  • PML
E10 / FILM + LESSON + PYTHON LAB

Designing light with gradients

Design a phase mask by measuring how each parameter affects an image, then replace thousands of separate perturbations with one adjoint calculation.

Key concepts
  • Inverse design
  • Adjoint method
  • Gradients
  • Automatic differentiation
  • Fabrication constraints
A COURSE YOU CAN TEST

A picture, a prediction, a calculation.

Each lesson opens with an optical problem and why solving it matters. Check the prerequisites, watch the five-minute film, then use controls that change the actual model and connect the result to a few equations. The Python lab then rebuilds the calculation, tests it independently, and asks you to explain what the model leaves out.

Allow 12–15 minutes for a lesson and 25–30 minutes for its core lab. Use the concept map to choose a starting point, then follow connections as questions arise. Review unfamiliar foundations using each lesson's preparation links. The modules work without the companion films.

Run notebooks in Colab or local Jupyter. They use NumPy, SciPy, and Matplotlib on CPU, with saved figures and no external datasets. Instructor notes provide a 45–50-minute classroom sequence and assessment rubric.
