E06 / 为什么学这一课？

透镜的厚度，有多少真正起作用？

紧凑光学系统需要很薄的聚焦元件。去掉材料会改变相位延迟，但在某个波长下，去掉整圈相位并不改变薄元件的透射函数。加工台阶与照明颜色变化，则会检验这种简化在多大范围内仍然有效。

你将学会： 将所需相位转为高度轮廓，估算只用少数高度等级的代价，并判断平面光学设计背后的波长范围和模型假设。

展开疑难逻辑

为什么去掉材料对一种颜色无害，对所有颜色却不成立？

1:13 · 回看这一段

h₂π = λ₀/[n(λ₀) − 1]
Δφ(λ) = 2π [λ₀/λ] [n(λ) − 1]/[n(λ₀) − 1]

在 λ₀ 处，去掉 h₂π 恰好改变 2π 相位，因此薄元件模型中的复透射不变。换一个波长，去掉的光程一般就不再是整数个波长。单一频率的相位相等，并不意味着群延迟或宽带波前也相等。

固定分区几何使设计衍射级次的焦距近似与波长成反比；进入该级次的功率还随浮雕相位深度的波长依赖而变化。视频中的百分比和色差例子针对所选元件，不代表所有平面光学元件或所有玻璃透镜。

为什么效率是 sinc²(1/N)，而不是与台阶数成正比？

2:23 · 回看这一段

sinc(u) = sin(πu)/(πu)
a₁ = N ∫[−1/(2N), 1/(2N)] e^(i2πu) du = sinc(1/N)
η₁ = |a₁|²

把每个台阶的相位与理想斜坡相比。一个等宽台阶内，相位误差扫过一小段圆弧；单位相量积分后的合成矢量会变短。N 个台阶对目标级次贡献相同且同向的合成矢量，因此得到上面的 sinc 振幅；功率则是振幅的模平方。

该结果假设无损、标量、均匀照明，以及对完整 2π 斜坡的理想 N 级量化。它是目标衍射级次的效率，并非总透射功率。反射、吸收、有限孔径、制造误差和矢量耦合还会进一步降低实际器件表现。

浮雕只有一微米高，为什么还可能不够“薄”？

3:36 · 回看这一段

近似 Uout(x) = t(x)Uin(x) 假设局部响应：x 处的光只受 x 处材料影响。物理高度小本身不足以证明这一点。横向传播、内部反射、高折射率反差、波长尺度结构及共振，都可能让很浅的结构中的相邻位置发生耦合。

超表面单元库通过求解单元中的麦克斯韦方程，改善局部振幅和相位响应的描述。但把不同单元相邻排列时，仍采用了局部周期近似。强梯度或强耦合可能需要完整器件计算；应针对实际几何与照明，用更完整模型检验近似。

01 / 建立直觉

先观察什么？

相对于周围介质，透明材料会延缓波的相位。在薄元件近似下，每个横向位置提供一个局部乘法因子。对于空气中折射率为 n 的玻璃，高度 h 产生相位延迟 φ = (2π/λ₀)(n − 1)h。该模型忽略光通过结构时沿横向发生的耦合。

U_out(x) = U_in(x)eiφ(x)   ·   h₂π = λ₀/(n − 1)

透镜让入射波的不同部分在焦点附近同相到达。近轴透镜具有二次相位分布。在任何位置加减整数倍的 2π，都不改变其复数乘法因子。因此，切掉对应整圈相位的厚度，就能得到最大高度小得多的包裹相位透镜，也称 kinoform。

演示采用无色散、n = 1.5 玻璃中的一维透镜截面。设计波长为 550 nm，因此整圈相位对应 1.10 μm 玻璃厚度。在所述薄元件模型下，未包裹轮廓与连续包裹轮廓在该波长产生相同光场。它们的几何形状不同，但复透射函数相等。

这种等效只针对指定波长和模型，并不意味着两个实际加工结构在麦克斯韦方程下散射完全相同，也不意味着它们在宽光谱范围内始终等效。

学完后，你能够

  1. 将实际高度转换为相位延迟。
  2. 解释为什么相位包裹在一个设计波长处等效。
  3. 定量分析台阶结构的效率，并识别薄元件模型何时失效。

03 / 理清逻辑

台阶是在近似一段相位旋转。

加工往往只能提供有限的高度等级。N 级台阶用 N 个常相位近似平滑相位斜坡。本应在同一衍射级次中同相相加的贡献会略有错位。因此，即使元件没有吸收，一部分功率仍会进入其他级次。

η₁ = sinc²(1/N),   sinc(x) = sin(πx)/(πx)

该表达式给出理想、均匀量化、覆盖完整 2π 的闪耀相位光栅在设计波长处的标量一级衍射效率。2、4、8、16 级对应约 41%、81%、95%、99%。它是局部 kinoform 环带的实用参考，但不能完整预测有限透镜的通光效率、加工损失或焦斑包围能量。

波长改变，也改变了被去掉的一圈相位的含义。

若 n 不变，在 λ₀ 处去掉的厚度 h₂π，在另一波长产生的相位是 2πλ₀/λ，通常不再是整数圈。因此包裹表面的干涉图案会随颜色改变。在近轴设计级次中，其焦距近似满足 f(λ) = f₀λ₀/λ。在本模型中，波长越长，焦点越靠近元件。

这里未包裹轮廓的折射率保持不变，所以其几何聚焦能力几乎与波长无关，但衍射光斑尺寸仍会变化。真实玻璃具有色散。Python 实验会明确区分这两点，避免将材料色散与相位包裹带来的更强波长依赖混淆。

何时局部相位还不够。

薄元件近似把各纵向柱状区域视为独立。陡峭侧壁、波长量级结构、反射、偏振依赖和谐振都可能在这些区域之间传递能量。把局部相位掩模采样得更细，无法补回缺失的物理机制。E07 和 E09 将引入能够描述耦合与全波散射的模型。

可选 Python 实验先平滑加工高度轮廓，再计算相位。这不同于平滑最终强度图：加工会在干涉之前改变光场。所有效率比较都使用相同的入射归一化，避免把各结果分别归一化到自身峰值而造成虚假的改善。
