章节索引

十个章节，多种入口。

章节编号用于标识内容。可以按概念或兴趣选择，再复习该课用到的基础知识。

E01 / 短片 + 课程 + PYTHON 实验

角谱法

换一种表示方式，追踪狭缝光场的传播：分离各个方向，推进它们的相位，再叠加起来。

E02 / 短片 + 课程 + PYTHON 实验

为什么透镜能做傅里叶变换

透镜把不同方向的平面波分到不同焦点。第二片透镜再把频谱变回图像，让你能够在两者之间修改它。

E03 / 短片 + 课程 + PYTHON 实验

衍射极限

探索点扩散函数、数值孔径，以及图像能够承载的空间频率。

E04 / 短片 + 课程 + PYTHON 实验

相干性与相机的平均过程

从同一个测量量——光场模平方的时间平均——理解干涉、光源带宽、光源尺寸和散斑。

E05 / 短片 + 课程 + PYTHON 实验

全息与相位问题

将相位差变成可测的条纹，从旁带恢复复光场，并理解迭代约束能够确定什么、又无法确定什么。

E06 / 短片 + 课程 + PYTHON 实验

平面光学与相位包裹

薄元件通过厚度控制相位。将相位包裹到一个周期内，可以得到很薄的光学元件；相位量化与波长变化则揭示这种简化的代价。

E07 / 短片 + 课程 + PYTHON 实验

光栅、布洛赫波与带隙

用动量匹配找出衍射方向，再用单周期传输矩阵解释为什么周期堆栈能阻挡某个频段。

E08 / 短片 + 课程 + PYTHON 实验

波导、模式与谐振器

找出能够保持形状传播的光场，将它们叠加以在波导间传递功率，再把多次往返相加，构建谐振。

E09 / 短片 + 课程 + PYTHON 实验

网格上的麦克斯韦方程

在交错网格上求解麦克斯韦方程中耦合的电磁场，理解时间步长、网格像素和计算边界为什么也是物理计算的一部分。

E10 / 短片 + 课程 + PYTHON 实验

用梯度设计光场

通过计算每个参数如何影响图像来设计相位掩模，再用一次伴随计算代替成千上万次独立扰动。

可以动手验证的课程

看一幅图，做一个预测，完成一次计算。

每节课都从一个光学问题出发，说明解决它的意义。先确认预备知识，再观看五分钟短片，然后调整实验参数，观察模型如何变化，并把结果与几条公式联系起来。Python 实验会重新实现计算、独立检验结果，并引导你思考模型忽略了什么。

每节课建议用时 12–15 分钟，核心实验约需 25–30 分钟。通过概念图谱选择起点，再沿着问题探索相关概念。遇到不熟悉的基础知识，可以使用各节课的预备知识链接复习。即使不看配套短片，也可以完成课程。

在 Colab 或本地 Jupyter 中运行实验。实验使用 NumPy、SciPy 和 Matplotlib，在 CPU 上即可完成，附有已保存的图表，无需外部数据集。教师说明提供 45–50 分钟的课堂安排与评分标准。
