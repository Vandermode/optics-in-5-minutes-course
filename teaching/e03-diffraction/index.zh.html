E03 / 为什么学这一课？

为什么继续放大不再显露更多细节？

你想在显微镜中分辨两个相邻的发光体。放大图像也会放大它们的模糊光斑，所以图像更大，并不能说明光学系统是否记录到了它们的间距。你需要把仪器参数与它实际记录的信息联系起来。

你将学会： 比较数值孔径与波长变化的效果，区分光学分辨率与显示缩放，并在尝试反卷积前判断测量图像能支持哪些细节。

01 / 建立直觉

每个点都会留下一个光斑。

点光源的像是一个艾里图样：明亮的中央光斑周围环绕着微弱的圆环。这就是透镜的 点扩散函数，简称 PSF。

对于彼此独立的发光点，例如荧光发射体，它们的 强度相加。扩展物体的像是这些光斑的叠加，即强度卷积： I = O ∗ h.

学完后，你能够

  1. 预测数值孔径与波长如何改变点扩散函数。
  2. 区分两点分辨判据与空间频率截止。
  3. 解释为什么放大与反卷积无法创造缺失的测量信息。

03 / 明确极限的含义

一片透镜，两个不同问题。

两个点

它们的图像重叠了多少？

dR ≈ 0.61 λ0 / NA

当点间距等于瑞利间距时，一个艾里图样的中央峰位于另一个的第一零点。本课中，这一约定适用于两个等亮且互不相干的点。

周期图案

哪些频率能传到图像中？

fc = 2 NA / λ0

非相干强度传递函数在这一截止频率降为零。其倒数 λ0/(2 NA) 是极限周期，而不是瑞利两点间距。在截止处，对比度已经为零。

艾里图样和系数 0.61 从哪里来？

对于圆形瞳孔，峰值归一化的强度点扩散函数为

h(r) = [2 J₁(v) / v]²,   v = 2π NA r / λ0.

J₁ 是一阶贝塞尔函数，根据极限有 h(0) = 1。其第一个正零点为 v ≈ 3.831706；除以 2π 得到 0.609835。两点图像为 h(√((x − d/2)² + y²)) + h(√((x + d/2)² + y²))。

查看传递函数，以及它与相干成像的区别

对于理想圆形瞳孔，当 0 ≤ ρ < 1 时，H(ρ) = (2/π)[arccos ρ − ρ√(1 − ρ²)]；当 ρ ≥ 1 时，H = 0。其中 ρ = |f|/fc。H 为非负实数，因此 MTF = |H| = H。

对于相干照明，瞳孔滤波的是 复光场 ，截止频率为 NA/λ0，之后才取强度。比较光场截止频率与强度截止频率时，必须说明物体和照明条件。本实验始终使用非相干发光体。
