E08 / 为什么学这一课？

如何在芯片上引导和储存光？

光路需要把光约束在波导内、转移到相邻通道，或在谐振器中积累。仅画出路径还不足以预测功率；结构支持的光场形状及其相对相位，才决定器件如何工作。

你将学会： 将约束条件与导模联系起来，根据模式拍频选择耦合长度，并解释往返相位、耦合和损耗如何决定环形谐振器的光谱响应。

01 / 建立直觉

先观察什么？

平板波导由高折射率芯层和低折射率包层组成。全内反射提示光可以留在芯层附近，但不是任意往返角度都能构成自洽的波。横向光场必须在两个界面匹配，并向包层内衰减；这些条件选出离散模式。

将模式写成 E(x,z) = ψ(x)eiβz。横向形状 ψ 保持不变，传播只增加相位。将这一形式代入标量波动方程，就得到特征值问题。

[d²/dx² + k₀²n²(x)]ψ = β²ψ   ·   n_clad < β/k₀ < n_core

β/k₀ 是有效折射率。这些不等式确定了无损平板中的导模。模式尾部是光场的一部分，不是应被裁掉的误差。接近截止时，尾部可深入包层，因此过小的模拟窗口会改变答案。

合适的输入可以展开为系统支持的模式。每个模式的形状不变，但它们的相对相位会变化。模式间干涉可使总强度从波导的一部分移动到另一部分。这就是导波系统中“先换基，再传播”的做法。

学完后，你能够

  1. 将导模识别为包层中具有衰减尾部的本征函数。
  2. 用超模间的相对相位解释定向耦合。
  3. 联系环形谐振、储能与临界耦合，同时区分振幅与功率。

调整参数之前，先做预测

波导可以支持多种横向形状。如果两个模式具有不同传播常数，它们的叠加是否仍保持相同的强度分布？

03 / 理清逻辑

相位逐渐分开，功率随之转移。

两个相邻且相同的波导支持对称与反对称超模，两者的传播常数略有不同。集中在一个波导中的输入可表示为这两个超模的叠加。若传播常数相差 2κ，经过 L = π/(2κ) 后相对相位达到 π，强度就转移到另一个波导。

P₁(z) = cos²(κz)   ·   P₂(z) = sin²(κz)

浏览器把 κ 作为理想无损双模模型的给定参数。Notebook 则从双波导折射率分布的特征值分裂计算 κ。波导不对称、辐射、额外模式或损耗，都可能阻止完全转移。

谐振器将光场与它自身的延迟副本叠加。

经过一次往返，环内光场乘以 ra eiφ，其中 r 是耦合器的自耦合振幅，a 是传播后的振幅保留因子，φ 是往返相位。将所有返回光场相加，得到正比于 1/(1 − ra eiφ) 的等比级数。在谐振处，各次返回相互增强。

由于能量能保留许多个往返，环内循环功率可以超过输入功率。这是储能，不是增益。驱动停止后，储能每次往返乘以 (ra)²。衰减时间与光谱线宽反映同一有限寿命。绝对品质因数还需要光学频率和往返时间，因此本页报告往返次数，而不凭空指定器件 Q 值。

t_through = (r − a eiφ)/(1 − ra eiφ)

在谐振处，当 r = a，直通端口消光。这就是临界耦合：直接透射的光与从环内泄漏回来的光相消干涉。在有损全通环中，缺失的直通功率在内部耗散；零透射并不意味着完全反射。若 a = 1，除奇异极限情况外，无损全通环的直通功率为 1，但相位仍会变化。
