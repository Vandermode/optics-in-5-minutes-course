E08 / 为什么学这一课？

如何在芯片上引导和储存光？

光路需要把光约束在波导内、转移到相邻通道，或在谐振器中积累。仅画出路径还不足以预测功率；结构支持的光场形状及其相对相位，才决定器件如何工作。

你将学会： 将约束条件与导模联系起来，根据模式拍频选择耦合长度，并解释往返相位、耦合和损耗如何决定环形谐振器的光谱响应。

展开疑难逻辑

许多光线都能全反射，为什么只有某些模式？

0:49 · 回看这一段

2kx d + φr,1 + φr,2 = 2πm
[d²/dx² + k₀²n²(x)] ψ = β²ψ

仅有横向限制还不够：场在横向传播并反射后，必须与自身一致。两个界面的反射相位都要计入往返条件。微分本征值问题通过边界匹配与包层中的衰减场，施加相同的自洽要求。

对简单无损阶跃折射率平板的束缚模，nclad k₀ < β < ncore k₀。上面标量矩阵的本征值是 β²，向前传播应取相应正平方根。并非每个数值本征向量都是导模：有限窗口还会把辐射态离散化。

光是在两根波导之间逐渐泄漏，还是模式在干涉？

2:15 · 回看这一段

β± = β₀ ± κ
a₁(z) = e^(iβ₀z) cos(κz), a₂(z) = i e^(iβ₀z) sin(κz)
P₂/Ptotal = sin²(κz), Ltransfer = π/(2κ)

在理想的相同无损波导对中，只激励一根波导等于对称与反对称超模的等权叠加。两者传播常数差为 2κ。传播 π/(2κ) 后，相对相位改变 π，于是在输入波导中相消、另一根波导中相长。

倏逝场重叠决定 κ，干涉则描述由此产生的功率交换。在 π/(4κ) 处得到 50:50 分光。两根波导传播常数不等时，最大转移率会下降，不能直接套用理想完全转移公式。

为什么储存时间越长，共振越窄？

3:25 · 回看这一段

energy: W(t) ∝ e^(−t/τE)
field: a(t) ∝ e^(−t/(2τE)) e^(−iω₀t)
ΔωFWHM = 1/τE, Q = ω₀τE = ω₀/ΔωFWHM

衰减较慢的场在更长时间内保持确定振荡，因此傅里叶响应集中在更窄频率范围。对指数衰减振幅作傅里叶变换，可得到洛伦兹功率共振。振幅寿命与能量寿命之间的二倍关系不能省略。

对孤立窄共振，Q ≈ λ₀/Δλ。加载寿命计入所有能量逃逸通道，包括向波导的有用输出。因此即使材料吸收不变，增强耦合也会使共振变宽。相邻共振之间的自由光谱范围是另一个量，不应与线宽混淆。

直通端口变暗时，能量去了哪里？

3:41 · 回看这一段

single-bus, on resonance: t = (γi − γe)/(γi + γe)
critical coupling: γe = γi

这里 γi 与 γe 是采用同一耦合模约定的内部和外部振幅衰减率。临界耦合时，直达场与环泄漏场在直通端口抵消。单总线有损环中，稳态下缺失的功率耗散于内部；启动过程中则有一部分功率先用于积累储能。

开场的加下载环具有第二根总线，它提供额外逃逸通道。输入总线的耦合率应匹配本征损耗与下载总线耦合率之和，才能使输入侧直通场抵消；功率可以从下载端口输出。无损单总线环在稳态下则是全通器件，不会在共振时吸收全部输入功率。

01 / 建立直觉

先观察什么？

平板波导由高折射率芯层和低折射率包层组成。全内反射提示光可以留在芯层附近，但不是任意往返角度都能构成自洽的波。横向光场必须在两个界面匹配，并向包层内衰减；这些条件选出离散模式。

将模式写成 E(x,z) = ψ(x)eiβz。横向形状 ψ 保持不变，传播只增加相位。将这一形式代入标量波动方程，就得到特征值问题。

[d²/dx² + k₀²n²(x)]ψ = β²ψ   ·   n_clad < β/k₀ < n_core

β/k₀ 是有效折射率。这些不等式确定了无损平板中的导模。模式尾部是光场的一部分，不是应被裁掉的误差。接近截止时，尾部可深入包层，因此过小的模拟窗口会改变答案。

合适的输入可以展开为系统支持的模式。每个模式的形状不变，但它们的相对相位会变化。模式间干涉可使总强度从波导的一部分移动到另一部分。这就是导波系统中“先换基，再传播”的做法。

学完后，你能够

  1. 将导模识别为包层中具有衰减尾部的本征函数。
  2. 用超模间的相对相位解释定向耦合。
  3. 联系环形谐振、储能与临界耦合，同时区分振幅与功率。

03 / 理清逻辑

相位逐渐分开，功率随之转移。

两个相邻且相同的波导支持对称与反对称超模，两者的传播常数略有不同。集中在一个波导中的输入可表示为这两个超模的叠加。若传播常数相差 2κ，经过 L = π/(2κ) 后相对相位达到 π，强度就转移到另一个波导。

P₁(z) = cos²(κz)   ·   P₂(z) = sin²(κz)

浏览器把 κ 作为理想无损双模模型的给定参数。Notebook 则从双波导折射率分布的特征值分裂计算 κ。波导不对称、辐射、额外模式或损耗，都可能阻止完全转移。

谐振器将光场与它自身的延迟副本叠加。

经过一次往返，环内光场乘以 ra eiφ，其中 r 是耦合器的自耦合振幅，a 是传播后的振幅保留因子，φ 是往返相位。将所有返回光场相加，得到正比于 1/(1 − ra eiφ) 的等比级数。在谐振处，各次返回相互增强。

由于能量能保留许多个往返，环内循环功率可以超过输入功率。这是储能，不是增益。驱动停止后，储能每次往返乘以 (ra)²。衰减时间与光谱线宽反映同一有限寿命。绝对品质因数还需要光学频率和往返时间，因此本页报告往返次数，而不凭空指定器件 Q 值。

t_through = (r − a eiφ)/(1 − ra eiφ)

在谐振处，当 r = a，直通端口消光。这就是临界耦合：直接透射的光与从环内泄漏回来的光相消干涉。在有损全通环中，缺失的直通功率在内部耗散；零透射并不意味着完全反射。若 a = 1，除奇异极限情况外，无损全通环的直通功率为 1，但相位仍会变化。
