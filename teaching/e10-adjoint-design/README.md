# E10 · Designing light with gradients

Design a phase mask by measuring how each parameter affects an image, then replace thousands of separate perturbations with one adjoint calculation.

## Learning outcomes

- Derive a real phase gradient through a complex Fourier operator.
- Verify that gradient with central finite differences.
- Explain why adjoints are not generally inverse propagation and why gradients do not guarantee global optimality.

## Use the lesson

Serve the complete teaching/ directory over HTTP. The lesson uses shared local assets and native JavaScript modules. Open this episode's folder in the browser. Its standalone notebook also works directly in Colab or Jupyter; it does not import repository code or require a GPU.

The notebook's core takes about 25–30 minutes to work through, with a separate optional extension. The first code cell installs numerical packages only when missing. Saved outputs, figures/, and figures.zip provide static figure access if a notebook frontend blocks rich output.

## Model and normalization

64 × 64 scalar phase-only pupil with a circular fixed amplitude and a unitary Fourier propagation operator. Targets have equal total power. No pixel coupling, material dispersion, noise, or fabrication constraints are included in the browser optimization. The optional Helmholtz example has a lossy boundary layer, explicitly not a PML.

Computed quantities are generated by model.js in the browser and the explicitly written NumPy/SciPy models in lab.py. Model-specific assertions and independent references are in the lab and the course checks. The browser and notebook use documented but not necessarily identical grid sizes. Synthetic randomness is seeded.

## Rebuild

From the repository root, run: python teaching/tools/build_course.py, then python teaching/tools/validate_notebooks.py. The authored page content and controls are in teaching/tools/curriculum.py; notebook source is this folder's percent-format lab.py. Building preserves saved outputs when notebook source is unchanged. Run npm test --prefix teaching for numerical browser-model tests.
