E05 / 为什么学这一课？

如何恢复强度图像隐藏的信息？

透明样品可以改变光学厚度，却几乎不改变焦内图像的亮度。然而，测量厚度或对记录的光场进行数值重新聚焦都需要相位。单张强度图像通常对应多个与测量一致的可能光场。

你将学会： 用参考波将相位编码到可测条纹中，并确定没有参考波时恢复相位所需的额外约束。判断一次成功重建究竟证明了什么。

展开疑难逻辑

慢探测器怎么能测光学相位？

0:58 · 回看这一段

I = |U|² + |R|² + UR* + U*R

探测器不必跟踪光学载波。若 U 与 R 的相对相位稳定，按光学周期平均后，它们共同的快速振荡在交叉项中消去。改变 U 相对于 R 的相位，会改变记录的亮度；两束光共有的未知相位仍不可见。

一个同轴强度值不足以同时确定振幅和相位。离轴全息增加空间载频与带宽约束；相移全息则测量多个已知参考相位。相干性、偏振重叠和参考校准决定交叉项能否用于定量恢复。

“载频至少是物体带宽的三倍”从哪里来？

2:02 · 回看这一段

object support: |f| ≤ B
|U|² support: |f| ≤ 2B
sideband support: fc − B … fc + B
separation: fc − B > 2B; sampling: fc + B < fNyquist

这里 B 指物体场的单边带宽，不是全宽 2B。场取模平方后产生差频谱，可延伸至 ±2B。理想平面参考下，每个交叉项边带的半宽为 B，中心位于 ±fc。避开中心谱要求 fc > 3B，保留外侧边缘又要求 fc + B 小于相机的奈奎斯特频率。

这是沿载频方向的一维保守支撑分析。真实二维频谱和非均匀参考需要检查实际支撑。截取后应把载频移回零，并补偿已知参考的振幅与相位；一个边带包含 U 乘参考的共轭，另一个则包含它的共轭孪生项。

为什么交替施加约束可能有效，却不保证得到真实相位？

2:55 · 回看这一段

U ← Aknown · exp[i arg(U)]
Ũ ← Bknown · exp[i arg(Ũ)]

每次振幅替换在保留当前相位猜测的同时，强制满足一项测量。平面之间的传播让另一项约束间接改变相位。固定点可能同时满足两处振幅约束，但约束集合是非凸的，因此可能停滞或存在多个解。

傅里叶幅度对全局相位、平移和共轭翻转保持不变。已知支撑可以排除其中一些自由度，却不能消除不可观测的全局相位或所有可能歧义。额外平面、重叠测量与独立验证，比单独一个很小的拟合残差提供更强的证据。

01 / 建立直觉

先观察什么？

相机通常记录时间平均强度，而不是复振幅 U = A eiφ。因此，许多不同光场可以产生同一幅相机图像。整体相位旋转会改变 U，但不会改变 |U|²。对于薄透明样品，相位延迟近似为 φ = (2π/λ₀)Δn h，它反映的是光学厚度而非吸收。

全息术引入已知的相干参考光 R。R 与 U 的干涉使测量对两者的相对相位敏感。展开测量强度是关键的第一步：它揭示哪些数据项包含所需光场。

|U + R|² = |U|² + |R|² + UR* + U*R

没有倾角的参考光会让各项在频率空间重叠。倾斜参考光 R = Arei2πf_cx 将两个交叉项向相反方向平移。因此，实值全息图的傅里叶变换包含中央背景和两个互为共轭的旁带。只要分离出一个旁带，即使相机只记录了实值强度，也能恢复复光场。

本页的模拟物体明确限制在半径 B = 8 个傅里叶格的带宽内，因此采样条件可以定量检验，而不只是凭图判断。已知参考光确定了振幅与相位约定，使显示的重建误差可以直接与输入光场比较。

学完后，你能够

  1. 将全息图展开为背景项与干涉项。
  2. 选择能够分离目标光场的载频和傅里叶裁剪范围。
  3. 区分有参考光的恢复与迭代相位恢复，并理解后者的歧义。

03 / 理清逻辑

频谱分离与采样必须同时满足。

如果 U 的带宽为 B，其强度 |U|² 的带宽可扩展到 2B。沿载频方向，以 f_c 为中心的旁带大致占据 f_c ± B。要与中央项分离，需要 f_c > 3B；要保持在采样频带内，还需 f_c + B < f_Nyquist。真实物体通常有频谱尾部，因此应留出余量，而不能依赖严格的有限频谱支撑。

这里的重建选择负载频项 UR*，将它平移到零频，做逆 FFT，再除以参考光振幅。若选择另一个旁带而不调整约定，就会得到共轭光场。如果参考光自身的相位未知，任意整体相位仍不可观测。恢复光场后，可以用 E01 的传播算子进行数值重新聚焦。

没有参考光时，依靠约束。

相位恢复从傅里叶幅值等测量出发，结合已知空间振幅或支撑范围等假设。Gerchberg–Saxton 算法在两个平面之间交替：传播、保留相位并把幅值替换为测量值、反向传播，再施加另一项约束。

U → F[U] → measured magnitude + current phase → F−1 → object constraint

每次投影都满足一个条件，但组合起来是非凸问题。残差很小并不自动证明物体唯一或正确。依实验而定，平移、共轭反转或整体相位都可能不改变测量结果。不同初值可能停滞在不同解。增加传播距离、已知参考光或扫描多样性，是在增加信息，而不只是增加迭代次数。

将测得幅值换成期望输出幅值，同一循环也能设计纯相位全息图。这属于合成问题：在输入振幅固定时，目标未必能够精确实现。Python 实验会报告残差并比较不同初值，而不保证精确收敛。
