E01 / 为什么学这一课？

光通过这个平面之后，会去哪里？

你知道狭缝或相位掩模后的光场，但探测器位于更远处。要预测探测到的图像，就必须追踪衍射和相位在空间中的演化。全息图的数值重新聚焦，以及检验光学设计是否产生预期图案，也会遇到同样的问题。

你将学会： 建立后续课程会复用的传播工具，预测孔径、波长和距离如何改变光场，并判断意外图案是否来自数值网格。

01 / 建立直觉

先观察什么？

狭缝挡住了入射波的一部分。刚通过开口时，光场集中在一条窄带内；传播到远处后，窄带之外也出现了明暗条纹。单靠直线光线无法解释这一图案：开口不同位置的贡献会发生干涉。

将单色光场写成 U(x) = A(x)eiφ(x)。复数可以看作箭头：长度表示振幅，角度表示相位。将这个复振幅乘以 e−iωt 后取实部，就得到物理电场。相机对快速振荡进行平均，记录的量正比于 |U|²。因此，强度相等并不意味着光场相同。

平面波的横向分布特别简单，即 eikₓx。沿 x 方向每单位距离，其相位增加 kₓ 弧度。傅里叶变换告诉我们每种分布包含多少。系数是复振幅，因此重建光场时必须保留它们的相位。

k = 2π/λ   ·   kₓ = 2πfₓ   ·   kₓ² + k_z² = k²

最后一个关系来自将平面波代入标量亥姆霍兹方程。它把横向频率与纵向传播常数联系起来。对于传播分量，sin θ = kₓ/k，因此空间频率图也对应着传播方向的分布。

学完后，你能够

  1. 将傅里叶系数解释为平面波振幅。
  2. 预测波长、孔径宽度和距离如何改变衍射。
  3. 区分物理上的倏逝衰减与数值上的混叠、周期回绕。

调整参数之前，先做预测

固定波长。如果把狭缝宽度减半，远处中央亮带会变窄还是变宽？先解释，再调整参数。

03 / 理清逻辑

传播变成了乘法。

在均匀空间中，各平面波分量独立演化。向前传播 z，相当于将每个系数乘以 H = eik_zz。各个方向积累不同的相位，因此总光场会改变形状，尽管每一个平面波本身都保持原来的形状。

U(x,z) = F−1{ F[U(x,0)] · eiz√(k²−kₓ²) }

当 |kₓ| 超过 k 时，取 k_z = i√(kₓ²−k²)，选择离开源后衰减的分支。此时传播因子是衰减的实指数函数。这是倏逝分量，而不是被孔径挡住的传播波。通过反向指数放大恢复它，会对噪声极其敏感。

在小角度下展开平方根，得到 k_z ≈ k − kₓ²/(2k)，即菲涅耳近似。它对窄角谱可能非常准确，但无法描述倏逝分支。切换模型属于物理近似；增加网格点数属于数值细化。Python 实验允许独立改变这两项。

FFT 隐含了一种边界条件。

离散 FFT 描述的是周期重复的窗口。如果衍射光场到达边缘，它可能从另一侧重新进入。零填充会拉开这些周期副本之间的距离，但不会提高空间分辨率：奈奎斯特频率仍由采样间距决定。在常规标量采样下，Δx ≤ λ/2 足以包含整个传播频带；倏逝结构可能需要更小的间距。

对于只含传播分量的频谱，|H| = 1，因此离散光场的范数守恒。狭缝还包含倏逝频率，其振幅平方会衰减。本页的功率比针对完整 FFT 网格，而非仅可见的中央裁剪区域；它是强度范数之比，并非严格的矢量场能流测量。

对照你的推理

比较两种宽度

狭缝宽度减半，理想远场的角尺度加倍；有限距离下的图案不一定严格遵循远场估计。

区分数值误差

零填充拉开周期副本之间的距离；更小的像素能够表示更高的空间频率。两者都不能代替收敛性检查。
