E04 / 为什么学这一课？

为什么光学元件没动，条纹却消失了？

即使两条光路都没有移动，改变照明或曝光条件也可能使干涉图案变淡。粗糙表面还可能产生稳定的散斑。要解释这些现象，就必须知道光场之间的哪些关系能够在相机平均后保留下来。

你将学会： 分析条纹可见度的变化，区分静态随机图案与相干性丧失，并判断成像模型何时应叠加光场、强度或相干模式。

展开疑难逻辑

光谱宽度怎么就变成了相干长度？

1:08 · 回看这一段

先把视频下方的图读成一次延迟扫描：横轴 ΔL 是同一光束的两个副本之间的光程差，τ = ΔL/c。快速振荡表示随光程差变化的干涉贡献，包络描述条纹可见度。它不一定是一段在空间中移动的有限光脉冲的形状。

对频率 ν，延迟副本会增加相位 2πντ。两个相差 δν 的频率，其干涉相位之差随延迟按 2πδντ 增长。零延迟时它们的条纹贡献一致；延迟增大后，贡献逐渐指向不同方向。连续频带的贡献就可能相互抵消，虽然每个频率仍在与自身副本干涉。

δφ = 2π δν τ = 2π δν ΔL/c
g⁽¹⁾(τ) = [∫ Sν(ν)e^(i2πντ) dν] / [∫ Sν(ν) dν]

Sν 是单位频率的功率谱密度。对平稳光场，它的归一化傅里叶变换就是复光场自相关 g⁽¹⁾（采用此处符号约定的维纳–辛钦关系），可见包络则是 |g⁽¹⁾|。与光谱构成傅里叶对的是复相关函数，而不只是实数包络。

Δν · τc ~ 1, ℓc = cτc ~ c/Δν
ν = c/λ ⇒ Δν ≈ cΔλ/λ₀² ⇒ ℓc ~ λ₀²/Δλ

最后一步假设 Δλ ≪ λ₀。在 550 nm 附近，30 nm 带宽给出粗略尺度 550²/30 nm ≈ 10 μm；带宽缩小十倍，这个尺度就变长十倍。这只是尺度估计：精确长度需要指定谱形和宽度判据。双线光谱甚至会出现相干复现，因此总带宽不能唯一确定所有相干函数。

下方实验采用高斯频率光谱，Δν 表示半高全宽。把 ℓe 定义为可见度降到 1/e 时的正光程差，就有 ℓe = 0.530 c/Δν；550 nm / 30 nm 的例子按此明确定义得到 5.34 μm。它与粗略的 10 μm 尺度描述的是同一光谱，但采用了不同的宽度约定。

Sν(ν) ∝ exp[−4 ln 2 · (ν − ν₀)²/Δν²]
|g⁽¹⁾(ΔL/c)| = exp[−(πΔνΔL/c)²/(4 ln 2)]
ℓe = (2√(ln 2)/π) c/Δν

小实验假设两束光等功率、偏振一致且处于同一空间模式，因此可见度等于 |g⁽¹⁾|。模型的光谱在频率域中为高斯形，Δλ 标签使用窄带换算。下方完整课程实验的带宽控件则采用频率标准差 σν，两者满足 ΔνFWHM = 2√(2 ln 2) σν。

不相干时，光场就不再相加了吗？

0:34 · 回看这一段

⟨|E₁ + E₂|²⟩ = I₁ + I₂ + 2 Re Γ₁₂
Γ₁₂ = ⟨E₁*E₂⟩, g₁₂ = Γ₁₂/√(I₁I₂)
V = [2√(I₁I₂)/(I₁ + I₂)] |g₁₂|

光场始终叠加。区别在于交叉项能否在测量平均后保留。不相关的相对相位在统计极限下给出 Γ₁₂ = 0，于是测得的强度相加；有限曝光仍可能留下残余涨落。

即使完全相干，也不保证可见度等于一：功率不平衡或偏振不匹配都会降低对比度。该公式假设扫描相位时两臂强度固定、偏振匹配。因此仅凭条纹很弱，还不能判断损失的是哪一种相干性。

针孔没有缩窄光谱，为什么也能恢复条纹？

1:56 · 回看这一段

Δφ(θ) ≈ 2π bθ/λ
gspatial(b) ∝ ∫ B(θ)e^(i2πbθ/λ) dθ

对间距为 b 的双缝，小源角 θ 产生与 bθ 成正比的相对相位。每个源点形成一套平移条纹；独立源点相加时，不同相位偏移会被平均。针孔缩小角度分布，使条纹在更大的缝间距下仍能对齐，同时也损失光功率。

这是不同位置之间的空间相干性；时间相干性比较的是延迟副本。窄光谱滤波主要改善后者，小角度光源主要改善前者。对全角宽 Θ 的均匀条形源，gspatial = sinc(bΘ/λ)，第一零点在 bΘ = λ；其他源形状会有不同零点，或者没有有限零点。

随机相位怎么还能形成稳定散斑？

2:49 · 回看这一段

空间上的随机不等于曝光期间不断变化。相干光照射静止粗糙墙面时，各路径的相位可以复杂却固定；它们叠加出固定的散斑。反复平均同一图样不会让它变平滑。

C = σI/⟨I⟩, Csum = 1/√N
Neff = (Σ wm)² / Σ wm²

C = 1 对应充分发展、被空间分辨、单偏振的理想散斑极限。N 个独立、等均值图样相加，方差按 N 增长、均值也按 N 增长，因此对比度变为 1/√N。权重不等时要用 Neff 替代 N；图样相关、像素平均和偏振也会改变结果。不同颜色或源点只有在产生不同图样时才有助于去散斑。

为什么对互强度做本征分解后，就可以把模式强度相加？

3:29 · 回看这一段

J(x₁,x₂) = ⟨U(x₁)U*(x₂)⟩ = Σ wm ψm(x₁)ψm*(x₂)
⟨am an*⟩ = wm δmn
Iout(x) = Σ wm |𝒫ψm(x)|²

J 是厄米半正定算子，因此本征值 wm 非负。将每个场实现展开到正交本征模式上，所得随机系数之间的交叉关联为零。经过线性传播 𝒫 后，交叉项仍在平均中消失，因此可以把加权模式强度相加。

这里需要的是“不相关”；统计独立是更强的条件。秩为一的 J 只需一个空间模式，可近似理想单模激光，但不适用于所有激光器。所需模式数取决于完整相关函数和精度要求，宽带传播还可能需要对波长积分。

01 / 建立直觉

先观察什么？

无论是否相干，两个电场都会叠加。变化的是探测器记录的平均值。对于偏振相同的两个标量光场，展开叠加场的模平方，就能看到产生干涉的那一项。

I = ⟨|U₁ + U₂|²⟩ = I₁ + I₂ + 2 Re⟨U₁U₂*⟩

尖括号表示对测量所采样的变化取平均。稳定的相对相位可以留下非零交叉项；若相位均匀遍历整圆，这一项就会消失。部分平均则产生中间程度的对比度。物理规律始终是光场叠加；强度相加是交叉相关为零时的结果。

将相关性归一化为 γ = ⟨U₁U₂*⟩/√(I₁I₂)，其模在 0 到 1 之间。条纹可见度为 V = (Imax − Imin)/(Imax + Imin)。本课的标量模型给出 V = 2√(I₁I₂)|γ|/(I₁+I₂)。只有两束光等亮且偏振匹配时，才有 V = |γ|。因此，仅凭对比度低还不足以判断相干性低。

这些参数描述一个刻意设为可分离的简化模型中的多种独立平均。相位抖动改变曝光期间的相对相位；带宽和延迟比较一束波及其延迟副本；光源角宽度对平移后的条纹取平均。散斑图则是另一项实验，用来区分实际平均了哪些图案。

学完后，你能够

  1. 将强度相加解释为交叉项平均后的结果。
  2. 区分时间相干性、空间相干性与固定的空间随机性。
  3. 用互强度和相干模式传播部分相干光。

03 / 理清逻辑

两种筛选，两种相关性。

时间相干性比较不同时间的光场样本。对于平稳光源，当干涉仪一臂延迟 τ 时，不同频率会产生不同的相位旋转。归一化光场相关函数是功率谱的傅里叶变换。对于标准差为 σν 的高斯频率分布，其模为 exp[−(2πσντ)²/2]。光谱滤波器缩窄频率分布，使干涉能够在更大的延迟范围内保持。

空间相干性比较不同位置的光场样本。每个光源点都能照亮两条狭缝，并与自身干涉。彼此独立的光源点对相机贡献的强度相加。不同照明角度会使条纹平移，因此扩展光源相当于平均多个平移副本。对于本课小角度、角分布均匀的条形光源，γ = sinc(Θd/λ)，其中 Θ 是全角宽度，sinc(x) = sin(πx)/(πx)。

针孔筛选角度，通常也会损失通量，但不会缩窄光谱。光谱滤波器筛选频率，却不会自动让扩展光源具有空间相干性。sinc 的负旁瓣会使条纹相移 π；它们不是负强度，而且第一个零点也不意味着此后永远没有相关性。

为什么随机相位仍会形成可见散斑。

静止粗糙表面施加不规则的空间相位。在稳定相干照明下，各贡献在曝光期间仍保持稳定干涉，形成固定的明暗颗粒。仅有空间随机性并不会把它们抹平。当测量同时叠加足够独立的不同图案、偏振、波长或未被分辨的颗粒时，对比度才会下降。

对于充分发展的、可分辨的单偏振散斑，对比度 C = σI/⟨I⟩ 约为 1。平均 N 个独立且等权的图案，得到 C ≈ 1/√N。重复同一个图案没有这种效果。有限图像尺寸与样本相关性会使测得的对比度在理想预测附近波动。

一个矩阵包含所有两两相关信息。

互强度为 Jᵢⱼ = ⟨UᵢUⱼ*⟩。其对角线是强度，而非对角线的相关性会影响传播后的结果。J 是厄米半正定矩阵，其特征向量是相干模式，非负特征值是各模式的功率。将每个模式通过同一个线性光场算子传播，再叠加加权强度即可。Python 实验将其与直接平均独立光源的结果比较，并演示如何测量模式截断误差。
